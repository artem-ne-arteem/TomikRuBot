# 📘 Примеры использования Томика

## 🚀 Быстрый старт

### 1. Добавление первой книги

Просто отправьте название книги боту:
```
Мастер и Маргарита
```

Бот найдёт книгу и предложит добавить. Или отсканируйте штрихкод:
- Сфотографируйте ISBN на обложке
- Отправьте фото боту
- Книга добавится автоматически

### 2. Inline-поиск в любом чате

В любом чате наберите:
```
@tomik_bot Война и мир
```

Выберите нужную книгу из списка — её описание отправится в чат.

### 3. Отслеживание прогресса

```
/timer          # Запустить таймер чтения
# ... читаете ...
[Стоп]          # В таймере нажать кнопку
120             # Указать, до какой страницы дочитали
```

Или вручную:
```
/read 50        # Записать 50 страниц за сегодня
```

## 📊 Работа со статистикой

### Просмотр статистики
```
/stats          # Полная статистика
/week           # Итоги недели
/heatmap        # Тепловая карта за 12 недель
/insights       # Персональные инсайты
```

### Цели
```
/goal 5         # Прочитать 5 книг в месяц
/goal off       # Отключить цель
```

### Уровень и достижения
```
/level          # Текущий уровень и XP
/badges         # Значки достижений
/profile        # Публичный профиль
```

## 📝 Заметки и цитаты

### Текстовые заметки
1. Откройте карточку книги
2. Нажмите 📝 Заметки
3. Выберите ➕ Цитата или ➕ Заметка
4. Отправьте текст

Для цитаты с указанием страницы:
```
Жизнь прекрасна, стр. 42
```

### Голосовые заметки
Вместо текста отправьте голосовое сообщение — оно сохранится как заметка.

### Экспорт
```
/export         # Все заметки в Markdown
```

## 🏷 Теги и организация

### Добавление тегов
1. Откройте карточку книги
2. Нажмите 🏷 Теги
3. Нажмите ➕ Новый тег
4. Отправьте теги через запятую:
```
фантастика, на лето, подарить
```

### Просмотр по тегам
```
/shelf          # Откроет полку
[🏷 Теги]       # Кнопка в полке
```

## 👥 Групповой режим

### Настройка группы

1. Добавьте бота в группу
2. Дайте права администратора (для управления)
3. Настройте:

```
/weekly on      # Итоги по понедельникам
/digest 21:00   # Вечерний дайджест в 21:00
/challenge 5000 # Цель: 5000 страниц на всех
/lang           # Язык группы
```

### Участие в рейтинге

```
/join           # Вступить в рейтинг
/top            # Посмотреть рейтинг
/read 30        # Записать страницы
/leave          # Выйти из рейтинга
```

### Книжный клуб

```
/club_create Читатели Достоевского    # Создать клуб (админ)
/club_join                             # Вступить
/club_book Преступление и наказание   # Установить книгу месяца (админ)
/club_info                             # Информация о клубе
```

## 🤖 Умные функции

```
/recs           # Что почитать дальше
```

Требует ANTHROPIC_API_KEY в .env. Без него работает поиск по авторам и жанрам.

### Прогнозы

```
/insights       # Показывает:
                # - Лучший день недели для чтения
                # - Любимый жанр в тренде
                # - Книги, которые слишком долго читаются

```

## 📥 Импорт и экспорт

### Импорт из Goodreads

1. Откройте [Goodreads](https://www.goodreads.com)
2. My Books → Import and export → Export Library
3. Скачайте CSV файл
4. Отправьте его боту с командой:
```
/import
```

### Экспорт данных

```
/export         # Заметки в Markdown
/export_csv     # Библиотека в CSV (для Goodreads)
/export_json    # Полный экспорт в JSON
/card           # Картинка для соцсетей
```

## 🎨 Картинка с итогами

```
/card           # Выбрать период:
                # - Месяц
                # - Год
                # - Всё время
```

Создаёт красивую картинку 1080x1350 для Instagram Stories или других соцсетей.

## 🔔 Напоминания

```
/remind 20:30   # Каждый день в 20:30
/remind off     # Отключить

/week on        # Итоги недели по понедельникам
/week off       # Отключить
```

## 📚 Примеры сценариев

### Сценарий 1: Я только начал книгу

```
1. Отправить название: "1984 Оруэлл"
2. Выбрать книгу из результатов
3. Нажать кнопку "📖 Читаю"
4. /timer — запустить таймер
5. Читаете...
6. Нажать "⏹ Стоп"
7. Указать: 45 (дочитал до 45 страницы)
```

### Сценарий 2: Дочитал книгу

```
1. /shelf — открыть полку
2. Выбрать книгу
3. Нажать "✅ Прочитано"
4. Выбрать оценку: ⭐⭐⭐⭐⭐
5. Нажать "📝 Заметки" → "➕ Заметка"
6. Написать впечатление
```

### Сценарий 3: Групповой челлендж

```
Админ:
/challenge 10000    # Цель: 10000 страниц на всех

Участники:
/join               # Вступить
/read 50            # Записывать страницы

Бот:
- Каждый день показывает прогресс
- В 21:00 — итоги дня
- Когда цель достигнута — поздравление
```

### Сценарий 4: Книжный клуб

```
Админ:
/club_create Клуб любителей фантастики
/club_book Дюна

Участники:
/club_join          # Вступить в клуб
# Добавляют "Дюну" на свою полку
# Читают и обсуждают в группе
# Отмечают прогресс

В конце месяца:
/club_book          # Показать текущую книгу
/club_book Солярис # Админ выбирает новую
```

## 💡 Полезные советы

### Для личного использования
1. Включите `/remind` и `/week on` для мотивации
2. Используйте теги для организации полки
3. Ставьте `/goal` на месяц — это работает!
4. Проверяйте `/insights` для прогнозов
5. Голосовые заметки удобнее текстовых

### Для групп
1. Начните с `/weekly on` и `/digest 21:00`
2. Установите реалистичный `/challenge`
3. Создайте книжный клуб для активности
4. Мотивируйте участников через `/top`

### Для экспорта
1. Делайте `/export` периодически — на всякий случай
2. `/export_csv` полезен для переезда на другие платформы
3. `/card` отлично подходит для соцсетей

## ❓ Частые вопросы

**Q: Как удалить книгу?**
A: Откройте карточку → нажмите 🗑 Удалить

**Q: Можно ли редактировать книгу?**
A: Да, в карточке есть кнопка ✏️ Изменить

**Q: Как работает inline-режим?**
A: В любом чате набирайте `@tomik_bot название` — откроется поиск

**Q: Зачем нужен таймер?**
A: Он автоматически считает время чтения для статистики

**Q: Можно ли импортировать из Livelib?**
A: Да, если там есть экспорт в CSV — просто отправьте файл с `/import`

**Q: Как получить больше XP?**
A: Читайте книги, записывайте страницы, поддерживайте серии, используйте таймер, добавляйте заметки

**Q: Где хранятся данные?**
A: Локально в файле `tomik.db` на сервере, где запущен бот

**Q: Можно ли использовать бота офлайн?**
A: Нет, нужен доступ к интернету для работы с Telegram API
