# История изменений

## [Версия 2.0.0] - 2026-10-18

### 🎉 Масштабное обновление!

#### ✨ Новые функции

**Inline-режим**
- Поиск книг прямо в любом чате через `@tomik_bot название`
- Результаты с обложками и подробной информацией

**Аналитика и визуализация**
- 📅 Тепловая карта активности (12 недель) — `/heatmap`
- 💡 Персональные инсайты и прогнозы — `/insights`
  - Лучший день недели и время для чтения
  - Тренды по жанрам
  - Предсказание даты дочитывания книги
  - Уведомления о "зависших" книгах

**Система уровней и геймификация**
- 🎖 Уровни читателя с XP — `/level`
- 👤 Публичные профили для шеринга — `/profile`
- 🏆 Расширенные значки достижений (8 ступеней вместо 6)
- Больше категорий наград

**Книжные клубы**
- 📚 Создание клубов в группах — `/club_create`
- 📖 Книга месяца для совместного чтения
- 👥 Участники и обсуждения
- `/club_join`, `/club_leave`, `/club_book`, `/club_info`

**Экспорт данных**
- 📥 CSV-экспорт библиотеки (совместим с Goodreads) — `/export_csv`
- 📥 JSON-экспорт (полные данные + API) — `/export_json`
- Исходный Markdown-экспорт заметок остался — `/export`

**Голосовые заметки**
- 🎤 Записывайте мысли о книгах голосом
- Автоматическое сохранение как текстовой заметки

#### 🔧 Улучшения

**База данных**
- Новые таблицы: `book_clubs`, `club_members`, `reading_insights`
- Улучшенная схема для аналитики

**Производительность**
- Оптимизированные запросы для больших библиотек
- Кэширование вычисляемых данных

**UX/UI**
- Обновлённое стартовое сообщение с группировкой команд
- Переработанное меню команд
- Улучшенная навигация

**Статистика**
- Более детальные метрики
- Красивое форматирование чисел (пробелы между разрядами)
- Расширенная система значков

#### 📚 Документация

- Подробный README.md с описанием всех функций
- EXAMPLES.md с реальными сценариями использования
- Улучшенный .gitignore

#### 🐛 Исправления
- Исправлена обработка голосовых сообщений
- Улучшена обработка ошибок при поиске книг
- Стабилизация работы inline-режима
