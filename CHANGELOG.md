# Обновление 1.3 — Крупное обновление 🚀

## ✨ Новые функции

### 🎯 Система челленджей (личные)
- **Команда `/challenge`** — создание и отслеживание личных целей
- **Готовые шаблоны:**
  - 📅 5 книг за месяц
  - 📅 10 книг за месяц
  - 🗓 50 книг за год
  - 🗓 100 книг за год
- **Визуальный прогресс:** прогресс-бары и отслеживание до даты окончания
- **Таблица в БД:** `challenges` — хранение активных челленджей пользователя

### ✍️ Система отзывов на книги
- **Кнопка "Написать отзыв"** в карточке книги
- **Полноценные отзывы** (не только оценки)
- **Отображение отзыва** в карточке книги
- **Таблица в БД:** `book_reviews` — хранение отзывов пользователей

### 📊 Расширенная статистика с трендами
- **Тренды чтения:** сравнение текущего месяца с предыдущим
- **Индикаторы изменений:** 📈 рост, 📉 снижение темпа
- **Улучшенное отображение:** показатели за 30 дней с трендами

### 🏆 Новые семейства значков
- **Челленджи:** за выполнение личных челленджей
- **Рейтинги:** за написание отзывов и оценок

## 🗄️ Изменения в базе данных

### Новые таблицы:
1. **`challenges`** — личные челленджи пользователей
   - `id`, `user_id`, `title`, `target`, `progress`, `start_date`, `end_date`

2. **`book_reviews`** — отзывы на книги
   - `id`, `user_id`, `book_id`, `review_text`, `created_at`

### Новые функции:
- `create_challenge()` — создание челленджа
- `get_active_challenges()` — получение активных челленджей
- `update_challenge_progress()` — обновление прогресса
- `save_review()` — сохранение отзыва
- `get_review()` — получение отзыва книги

## 📝 Обновлённые тексты

### Русский язык:
- `challenge_*` — 10+ новых ключей для челленджей
- `review_*` — 4 новых ключа для отзывов
- `trend_*` — 2 ключа для трендов

### Английский язык:
- Полные переводы всех новых ключей

## 🎨 UI улучшения

- Новая кнопка "✍️ Написать отзыв" в карточке книги
- Прогресс-бары для челленджей с эмодзи
- Улучшенная визуализация трендов в статистике
- Добавлена команда `/challenge` в меню

## 🔧 Технические детали

- Добавлено 2 новых обработчика callback'ов для челленджей
- Расширена функция `stats_text()` — теперь показывает тренды
- Обновлена функция `book_text()` — отображение отзыва
- Добавлен обработчик текста для приёма отзыва

## 📌 Совместимость

- **Обратно совместимо** со всеми существующими данными
- База данных автоматически создаст новые таблицы при запуске
- Все старые функции работают без изменений
