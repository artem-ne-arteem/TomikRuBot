# 📚 Томик — Умный книжный бот для Telegram

Полнофункциональный бот для ведения читательского дневника, трекинга прогресса чтения и книжных клубов в Telegram.

## ✨ Основные возможности

### 📖 Управление библиотекой
- **Быстрое добавление книг**: поиск по названию через Google Books и Open Library
- **Сканирование штрихкодов**: добавление книг по ISBN через фото
- **Inline-режим**: `@tomik_bot название` — поиск книг в любом чате
- **Статусы**: хочу прочитать, читаю, прочитано, брошено
- **Теги**: организация книг по категориям
- **Заметки и цитаты**: с указанием страниц
- **Голосовые заметки**: записывайте мысли о книгах голосом

### 📊 Аналитика и статистика
- **Тепловая карта активности**: визуализация чтения как на GitHub
- **Персональные инсайты**: 
  - Лучшие дни и время для чтения
  - Тренды по жанрам
  - Предсказание даты дочитывания
  - Уведомления о "зависших" книгах
- **Подробная статистика**: книги, страницы, время чтения, серии дней
- **Графики и диаграммы**: визуализация прогресса

### 🎮 Геймификация
- **Система уровней**: прокачивайтесь, читая книги
- **Значки достижений**: за книги, страницы, серии, часы, заметки, жанры
- **Публичные профили**: делитесь статистикой с друзьями
- **Рейтинги**: соревнуйтесь в группах

### ⏱ Трекинг чтения
- **Таймер чтения**: автоматический учёт времени
- **Прогресс по страницам**: отслеживание с процентами
- **Журнал чтения**: вся история по дням
- **Серии дней**: мотивация читать каждый день

### 🎯 Цели и напоминания
- **Цели на месяц**: сколько книг хотите прочитать
- **Ежедневные напоминания**: в выбранное время
- **Еженедельные итоги**: по понедельникам
- **Прогресс к цели**: с визуальным прогресс-баром

### 🤖 Умные рекомендации
- **На основе оценок**: книги похожих авторов и жанров
- **AI-рекомендации**: персональная подборка через Claude
- **Умный поиск**: релевантные результаты

### 👥 Групповые функции
- **Рейтинги чтения**: кто сколько прочитал
- **Групповые челленджи**: общая цель на месяц
- **Книжные клубы**: совместное чтение и обсуждения
- **Ежедневные и еженедельные дайджесты**: итоги активности

### 💾 Экспорт данных
- **Markdown**: заметки и цитаты
- **CSV**: совместимость с Goodreads
- **JSON**: полный экспорт для программистов
- **Картинка-итоги**: для соцсетей

## 🚀 Установка и запуск

### Требования
- Python 3.11+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

```bash
# Клонировать репозиторий
git clone <url>
cd tomikru

# Установить зависимости
pip install -r requirements.txt

# Создать .env файл
cat > .env << EOF
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
ANTHROPIC_API_KEY=ваш_ключ_для_ai_рекомендаций  # опционально
GOOGLE_BOOKS_KEY=ваш_ключ_google_books  # опционально, но рекомендуется
EOF

# Запустить бота
python bot.py
```

### Опциональные настройки в .env

```bash
# Прокси (если нужен)
PROXY=http://127.0.0.1:8080

# Часовой пояс (по умолчанию Europe/Moscow)
TZ_NAME=Europe/Moscow

# Картинка для /start
START_PHOTO=start.png

# Модель для AI-рекомендаций (по умолчанию claude-haiku-5-5)
ANTHROPIC_MODEL=claude-sonnet-4

# Шрифты для картинок с итогами
FONT_BOLD=/path/to/bold.ttf
FONT_REG=/path/to/regular.ttf
```

## 🎯 Особенности реализации

### База данных
SQLite с автоматической миграцией схемы при обновлениях:
- `books` - библиотека пользователей
- `notes` - заметки и цитаты
- `reading_log` - журнал чтения (страницы и время)
- `tags` - теги для организации
- `sessions` - сессии таймера
- `badges` - значки достижений
- `book_clubs` - книжные клубы
- `reading_insights` - вычисленные инсайты
- `chat_groups` - групповые чаты
- `group_members` - участники рейтингов

### API интеграции
- **Google Books API**: основной поиск книг
- **Open Library API**: резервный поиск
- **Anthropic Claude API**: AI-рекомендации (опционально)
- **ZXing**: распознавание штрихкодов

### Архитектура
- Асинхронная обработка (aiogram 3.x)
- Роутеры для личных и групповых чатов
- Middleware для трекинга пользователей
- Фоновые задачи для напоминаний
- Автоматическое резервное копирование БД

## 🌍 Мультиязычность

Поддерживаемые языки:
- 🇷🇺 Русский (по умолчанию)
- 🇬🇧 English

Язык определяется автоматически при первом запуске, но можно изменить через `/lang`.

## 🔒 Приватность

- Все данные хранятся локально в SQLite
- Никакой отправки данных на сторонние серверы (кроме поиска книг и AI-рекомендаций)
- Резервные копии делаются локально
- Можно полностью удалить свои данные
