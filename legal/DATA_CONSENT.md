## 📋 Что вы соглашаетесь:

### ✅ Соглашаетесь на сбор:
- **Telegram ID** — для идентификации
- **Имя пользователя** — для отображения
- **Язык** — для локализации
- **Информация о книгах** — для вашей библиотеки
- **Страницы чтения** — для отслеживания прогресса
- **Заметки и цитаты** — для вашего дневника
- **Настройки** — для напоминаний и целей

### ✅ Соглашаетесь на обработку:
- 📊 Создание статистики и инсайтов
- 📈 Анализ привычек чтения
- 🎯 Отслеживание челленджей и целей
- 👥 Рейтинги в группах
- 🏆 Присвоение значков и достижений

### ✅ Соглашаетесь на хранение:
- Локальная база данных на сервере
- Резервные копии на 14 дней
- До тех пор, пока используете сервис

### ✅ Соглашаетесь на передачу:
- **Google Books API** — для поиска книг (название, автор)
- **Open Library API** — для данных о книгах
- **Anthropic API** — для рекомендаций (опционально)
