# Уведомление о безопасности данных — Томик

**Дата вступления в силу:** 18 октября 2026 г.

---

## 🛡️ Наша приверженность безопасности

Мы серьёзно относимся к защите ваших данных. Этот документ описывает технические и организационные меры безопасности, которые мы применяем.

---

## 🔐 Технические меры безопасности

### 1. Шифрование данных:
- ✅ **HTTPS** — все соединения с Telegram API шифруются
- ✅ **TLS/SSL** — безопасная передача данных
- ✅ **Локальная БД** — данные хранятся локально, не в облаке

### 2. Хранение данных:
- 🗄️ **SQLite база** — файл `tomik.db` на защищённом сервере
- 🔑 **Ограниченный доступ** — только серверный код имеет доступ
- 📦 **Резервные копии** — шифрованные, локальное хранение

### 3. Аутентификация:
- 👤 **Telegram ID** — используем для идентификации
- 🔐 **API ключи** — хранятся в переменных окружения
- 🚫 **Без паролей** — Telegram уже обеспечивает безопасность

### 4. Мониторинг:
- 📊 **Логи ошибок** — отслеживание проблем
- 🚨 **Уведомления** — админ получает алерты о сбоях
- 🔄 **Автообновления** — регулярные патчи безопасности

---

## 🚧 Ограничения доступа

### Кто имеет доступ:
- ✅ **Администратор бота** — полный доступ к БД
- ✅ **Серверный код** — автоматизированная обработка
- ❌ **Сотрудники** — нет доступа (сервер одноразовый)

### Что они могут видеть:
- ✅ **Данные пользователя** — только для отладки ошибок
- ✅ **Логи ошибок** — техническая информация
- ❌ **Пароли** — их нет (Telegram auth)

---

## 🔄 Резервное копирование

### Автоматическое:
- 📅 **Ежедневно в 04:00** — автоматическая копия базы
- 📦 **14 дней** — хранение старых копий
- 🗑️ **Автоудаление** — старые копии удаляются

### Ручное:
- 💾 **Команда `/backup`** — для админа
- 📤 **Отправка файла** — владельцу бота

### Восстановление:
- 🔧 **Техническая поддержка** — при сбоях
- ⚡ **Быстрое восстановление** — из последней копии
